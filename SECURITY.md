# Security Policy

## Supported versions

No stable version has been released. Only the currently maintained default
branch, `main`, receives fixes. No tag or release exists yet, so no earlier
version is supported.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Anything else | Nothing else exists |

## Reporting a vulnerability

Report privately through GitHub. Open the repository's **Security** tab and
choose **Report a vulnerability**, which opens a private advisory visible only
to the maintainer.

**Do not open a public issue, discussion or pull request for a suspected
vulnerability**, and do not describe one in a public comment. Private reporting
is the only channel offered.

A useful report states what was observed, the affected file, endpoint or
setting, the input or steps that reproduce it, the impact you believe it has,
and the commit you tested against.

No response time and no remediation deadline are promised. This project is
maintained by one person, and reports are reviewed as capacity allows.
